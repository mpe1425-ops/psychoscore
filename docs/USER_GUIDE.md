# Инструкция пользователя ПсихоСкор

## 1. Начало
Откройте сайт и нажмите «Открыть программу». При первом входе запустится обучение (потом — кнопка «? Обучение»). Сайт можно установить как приложение (значок в адресной строке браузера) — тогда он работает без интернета.

## 2. Где хранятся данные
Только в вашем браузере. Очистка браузера их удалит. Нажмите **«💾 Сохранить в файл»** — в Edge/Chrome дальнейшие изменения будут записываться в выбранный файл автоматически. Восстановить или перенести данные на другой компьютер: **«📂 Открыть файл»**. Делайте копию регулярно.

## 3. Создание методики (вкладка «Настройка»)
1. **+ Новая методика**, укажите название и категорию (категории группируют список слева).
2. **Варианты ответов** — выберите шаблон (1–5, 1–7, −3…+3, Да/Нет, Да/Нет/Не знаю) или впишите свои строки «подпись;баллы». Баллы сохраняются сразу.
3. **Пункты** — добавляйте по одному или списком. Галочка **«зеркальный»** включает обратный подсчёт (1↔5, 2↔4; для −3…+3 знак меняется).
4. **Шкалы** — название, номера пунктов («1-5, 8, 10»), формула. Один пункт может входить в несколько шкал.
   - `sum` — сумма, `avg` — среднее по отвеченным пунктам.
   - Своя формула: `sum*2+5`, `avg/n`; доступны `n` (число учтённых пунктов), `i1…iN` (баллы пунктов), `s1…sK` (результаты предыдущих шкал), `Math`.
5. **Перевод в стандартные баллы** — выберите z, T, стены или станайны и укажите для каждой шкалы среднее и σ из норм.

## 4. Шаблоны
**★ Сохранить как шаблон** запоминает всю настройку (без данных испытуемых). **★ Создать из шаблона** — новая методика в один клик. Кнопка ⬇ в списке шаблонов скачивает шаблон файлом для коллеги; он загружает его кнопкой «📂 Загрузить шаблон из файла».

## 5. Ввод данных (вкладка «Ввод данных»)
- Ответ — баллом или подписью («Да»). Пустая клетка — пропуск (не учитывается).
- **Загрузить из Excel / CSV**: `.xlsx`, `.xls`, `.csv`, `.txt`. Первый столбец — ФИО/код (если включён), далее ответы по порядку пунктов. Заголовки определяются автоматически или задаются вручную.
- **Ctrl+V** в любой клетке вставляет блок ячеек, скопированных из Excel, начиная с этой клетки. Enter — вниз по столбцу.
- Галочка «столбец ФИО / код» выключает имена: строки нумеруются.
- ⌫ в строке — очистить ответы строки, ✕ — удалить строку, ⌫ над столбцом — очистить столбец, «🗑 Удалить все ответы» — очистить всю таблицу методики.

## 6. Результаты
Вкладка «Результаты» считает всё автоматически. «n» — сколько пунктов учтено в шкале. **Выгрузить в Excel** сохраняет таблицу `.xlsx`.

## 7. Частые вопросы
- *Пропали данные* — вероятно, очищен браузер; откройте резервный файл.
- *Столбцов в файле больше/меньше, чем пунктов* — программа покажет предупреждение; проверьте порядок столбцов.
- *Формула даёт «ошибка»* — проверьте номера пунктов и допустимые символы.

⚠️ Программа — вспомогательный инструмент; ответственность за ключи, нормы и интерпретацию — на специалисте.
