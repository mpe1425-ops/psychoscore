# ПсихоСкор

Бесплатный веб-конструктор подсчёта баллов по психологическим методикам. Работает целиком в браузере: **данные никуда не отправляются** и хранятся на устройстве пользователя. Статус: бета.

Возможности: любые методики и шкалы ответов, зеркальные пункты, шкалы с пунктами в нескольких шкалах, формулы (`sum`, `avg`, своя), перевод в z/T/стены/станайны, шаблоны и категории, обмен шаблонами файлом, импорт `.xlsx/.xls/.csv` и вставка из Excel, выгрузка `.xlsx`, светлая и тёмная тема, адаптация под телефон, установка как PWA (работа офлайн).

Инструкция для пользователей: [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

> ⚠️ Программа — вспомогательный инструмент. Ключи, нормы и интерпретация остаются на ответственности специалиста. Готовых методик в репозитории нет.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий и загрузите в него все файлы этого проекта (включая скрытую папку `.github`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Каждый push в ветку `main` запускает тесты и публикует сайт: `https://<логин>.github.io/<репозиторий>/`.

## Разработка
```
npm install
npm run dev     # локальный сервер
npm test        # тесты подсчёта баллов
npm run build   # сборка в dist/
```
Структура: `src/engine.js` — чистая логика подсчёта (зеркальные баллы, формулы, нормы, разбор CSV), покрыта тестами в `tests/`; `src/main.js` — интерфейс; `src/style.css` — оформление и темы.

Формат файла данных/шаблонов — JSON (поля `ms` — методики, `tpl` — шаблоны). Сторонний код: [SheetJS](https://sheetjs.com) (Apache-2.0).
