Тест личностных акцентуаций (ЛА) — автоматическая обработка

По методике В.П. Дворщенко (модификация ПДО А.Е. Личко), 2002. Данные обрабатываются в браузере и никуда не отправляются.

Параметры обследуемого

Пол нужен для правила «М < Ф» (применяется только к юношам). Для пакетной обработки параметры общие.

1. Загрузить файл (CSV / XLSX)

Допустимы: строка из 195 значений; столбец из 195 значений; два столбца «№ — ответ»; несколько строк (по одному обследуемому в строке, первая ячейка может быть ФИО). Значения от −3 до +3.

2. Вставить из Excel / текста

3. Заполнить бланк

Введите ответ для каждого утверждения: от −3 до 3. Enter / пробел / Tab — к следующей ячейке. Пустые ячейки считаются как 0.

Ключи шкал

Формат: «ДА» и «НЕТ» — номера пунктов через пробел; вес, если он не 1, указывается через двоеточие (85:2, 96:-3). Ответ +3 засчитывается по ключу «ДА», −3 — по ключу «НЕТ». Изменения действуют до перезагрузки страницы (можно сохранить в JSON).

Правила расчёта

По умолчанию подставлены значения из «Шпаргалки ТЛА». Меняйте, нажимайте «Применить» — результаты пересчитаются, а вкладка «Результаты → Как посчитано» покажет, какое правило сработало и с какими значениями. Настройки сохраняются в браузере.

Справка по синтаксису

Переменные: Д Т Г Ц Л А С П Ш Э И Н d В К Е М Ф V (суммы по ключам; в допбаллах — см. режим), муж (1 для юноши), а также имена производных параметров (D, Dпол, Дх, Nc, S…) — ниже по списку можно использовать только выше определённые. Операторы: + − * / ( ) < > <= >= == != && || ! (допустимы ≥ ≤ ≠, одиночное «=», слова «и»/«или»). Логические выражения равны 1/0, поэтому их можно складывать: (Г<=2)+(С>=7). Функции: есть('Г') — тип входит в итоговый диагноз (1/0), типов — число итоговых типов, крит('Сд') — число сработавших критериев по таблице ниже. Латинские A B C E H K M T воспринимаются как кириллические.

Допбаллы: условие -> шкала+N; шкала-N, одно правило в строке, # — комментарий. Группы: префикс @имя: объединяет правила в группу — применяется только первое сработавшее сверху вниз (так за В=7 начислится только Э+2, а не Э+1 и Э+2). Пол: муж и жен (1/0) берутся из поля «Пол», например (муж&&М<Ф). Интерпретация: строки x>=2: текст (проверяются сверху вниз, срабатывает первая), иначе: текст — по умолчанию.

4. Критерии по типам

Формат: Тип: условие | условие | …. Считается число различных сработавших условий среди выраженных типов (используется функцией крит('…')).

Сд (социальная дезадаптация)
Врл (расстройство личности)

В «Шпаргалке» часть условий для Сд/Врл распознана с искажениями; где текст неясен, оставлены значения из основного текста книги. Проверьте: Сд для Н (А+С+П ≥ 5), Врл для Ш (Г=1, Л=1 — в основном тексте «Г<1, Л<1»), Врл для Э (К<1), Дх — условия с «и» поняты как одновременные (И, а не ИЛИ).
